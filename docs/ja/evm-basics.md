# EVMの読み方

EVM（Earned Value Management、アーンドバリューマネジメント）は、「計画」「出来高」「実績」の3つの値を比べて、プロジェクトの遅れやコストの超過を数字で見る手法です。このページでは、プラグインの画面に出る値の意味と読み方を説明します。

[目次に戻る](index.md)

## 1. 基本の3つの値

このプラグインでは、値の単位は「時間」です（表の下段は、共通設定の「一日の基準時間」で割った日数）。

| 値 | 名前 | このプラグインでの計算 |
| --- | --- | --- |
| **PV** | 計画価値（Planned Value） | 各チケットの予定工数を、開始日から期日までの作業日に均等に割り振り、基準日までを合計したもの |
| **EV** | 出来高（Earned Value） | 終了したチケットの予定工数。進捗率が設定されている場合は、進捗率を変更した日に「予定工数 × 進捗率」を計上 |
| **AC** | 実コスト（Actual Cost） | 計算対象のチケットに記録された作業時間の合計 |

ひとことで言うと、PVは「今日までに終わっているはずの量」、EVは「実際に終わった量」、ACは「実際にかかった時間」です。

## 2. 差異と効率

| 値 | 計算 | 読み方 |
| --- | --- | --- |
| **BAC** | 全チケットの予定工数の合計 | プロジェクト全体の計画量 |
| **Complete EV** | EV ÷ BAC | 全体のうち何%終わったか |
| **SV** | EV − PV | マイナスなら遅れ |
| **CV** | EV − AC | マイナスならコスト（作業時間）超過 |
| **SPI** | EV ÷ PV | 1未満なら遅れ。0.8なら「予定の8割のペース」 |
| **CPI** | EV ÷ AC | 1未満なら超過。0.8なら「1時間の作業で0.8時間分しか進んでいない」 |
| **CR** | SPI × CPI | スケジュールとコストを合わせた総合的な効率。1以上なら良好 |

SPI・CPI・CRは、共通設定の閾値以下だと赤、閾値より大きく1未満だとオレンジで表示されます。

## 3. 予測

| 値 | 計算 | 読み方 |
| --- | --- | --- |
| **ETC** | 残作業の見積もり（下の表を参照） | これから何時間かかるか |
| **EAC** | AC + ETC | 完了までに全部で何時間かかるか |
| **VAC** | BAC − EAC | マイナスなら、完了時に計画より超過する見込み |
| **TCPI** | (BAC − EV) ÷ (BAC − AC) | 残りの予定工数で終えるのに必要な効率。1より大きいと、今より効率を上げないと計画内に収まらない |

ETCの計算方法は、共通設定で3つから選びます。

| 共通設定の選択肢 | 計算 | 考え方 |
| --- | --- | --- |
| 楽観的 | BAC − EV | 残りは計画どおりの効率で進む |
| 普通 | (BAC − EV) ÷ CPI | 残りも今までと同じコスト効率で進む |
| 悲観的 | (BAC − EV) ÷ CR | 残りも今までと同じコスト効率とスケジュール効率で進む |

プロジェクトが完了すると、予測の値は「-」と表示されます。

## 4. ES（アーンドスケジュール）

EVMのSVやSPIは「時間（工数）」の単位なので、「何日遅れているか」が分かりにくく、またプロジェクトの終盤では、遅れていてもSPIが1に近づいていく性質があります。ESは、これを「日数」で見るための指標です。EVMタブの隣の **ES** タブに表示されます（単位は日数）。

| 値 | 意味 |
| --- | --- |
| **SAC** | 計画の所要日数（開始日から終了日までの作業日数） |
| **ES** | 今のEVに、計画上は何日目で達するはずだったか |
| **AT** | 開始日から基準日（完了していれば完了日）までの作業日数 |
| **TV** | ES − AT。マイナスなら、その日数だけ遅れている |
| **TPI** | ES ÷ AT。1未満なら遅れ |
| **TEAC** | SAC ÷ TPI。今のペースで進んだ場合の総日数 |
| **TVAC** | SAC − TEAC。マイナスなら、その日数だけ完了が遅れる見込み |

## 5. グラフの読み方

### EVMチャート

PV・EV・ACの累積値を日付ごとに表示します。

- **EVの線がPVの線より下** にあれば遅れ、**ACの線がEVの線より上** にあれば超過です。
- ベースラインを使っている場合は、ベースラインのPVも表示されます。今のPVとの差が、計画の変更（チケットの追加や期日の変更）です。
- 共通設定で「予測値の表示」を有効にすると、完了までの予測の線も表示されます。

### パフォーマンスチャート

SPI・CPI・CRの推移を表示します。PV・EV・ACが計算されている日だけを使うので、メンバーがこまめにチケットを終了し、作業時間を記録しているほど、値の精度が上がります。

## 6. よくある読み違い

- **作業時間を記録していないと、CPIは計算されません**（ACが0のとき、CPIは0と表示されます）。CPIが0のときはETCも0になり、EACはACと同じ値になります。
- **チケットを終了にするまで、EVはほとんど増えません**。進捗率を使わない運用では、大きなチケットが1枚終わった日にEVが一気に増えます。チケットを1〜3日程度の粒度に分けると、グラフが実態に近づきます。
- **予定工数の入っていないチケットは、PVにもEVにも何も加わりません**。作業時間だけが記録されると、ACだけが増えてCPIが下がります。
